# Spike S3 — captura de teclas

App descartável que mostra, para cada tecla pressionada, o código físico do Flutter e o código evdev
calculado (`KEY_*`). Procedimento e resultados: documentação privada do mantenedor (`docs/spikes.md`).

```bash
flutter build linux --debug && ./build/linux/x64/debug/bundle/nexo_s3_keys
```
